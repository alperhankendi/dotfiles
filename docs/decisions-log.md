# Decisions taken during implementation

This project was built by an agent-driven process: sixteen tasks, each independently
reviewed, most with a fix round. Where the plan turned out to be wrong, or a question
arose that the plan did not answer, a decision was made and recorded rather than
quietly resolved. Every one of them is below, in the order they were made, so the
owner can see what was decided on their behalf and reverse anything they disagree with.

The build produced 46 commits and was never pushed until the owner approved it.
